# Impeccable 卡带控制台审核与修改

2026-10-08。本轮以工作区已有的未提交 Cassette Futurism 实现为起点；用户确认完善首页与监测页、保留全部功能，并选择直接修改代码与截图验收。没有重置工作区、修改后端、启用自动 hook 或执行真实蓝牙扫描。

## 结果

炭灰／军绿模块、米色卡带、压字标签、螺丝、琥珀／橙／铁锈条纹和黑底 CRT 保留。荧光绿与琥珀读数使用本地 IBM Plex Mono；红色只出现在警示灯。有限步进动效保留，旋钮换档增加一次 250ms／3 步雪花，减少动态效果时关闭。

已修复：

1. 设备按钮与对比拨杆通过稳定 aria-describedby 提供 RSSI、强弱、接收状态和地址；设备详情补充上次信号强度。Chromium 可访问树确认描述真实存在，未将列表设为持续播报。
2. WebSocket 断线后适配器读数显示“未知”，重连等待新状态时不把缓存状态当成当前事实；历史记录仍保留。
3. 连接中、扫描等待、待命、异常和搜索无结果分别给出对应提示；全部曲线隐藏时提供图例恢复和查看数据入口。
4. 数据表分页通过 polite live region 播报新页码。
5. touchcancel 和窗口失焦清理列表交互标记，防止自动排序一直暂停。
6. 功能文字由原先 8–10px 提高到至少 11px，中文副标题和英文大标题字距收紧至可读范围；补齐文本选择色与输入光标色。
7. 旋钮补充可见及可访问的点击／方向键提示；RSSI 数字与条形读数保持同一强弱色义。
8. 独立截图审核发现 320px SYS 状态断词；≤400px 改为 PWR／SCAN 两列、RX 下一行，不降低字号和操作目标。扫描中、正在启动、正在停止、需要处理四状态均测得一行文字。
